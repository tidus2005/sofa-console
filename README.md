# 沙发控制台 · Sofa Console

一个 Windows 托盘工具，把**显示器与电视切换、声音输出、鼠标侧键快捷操作**放进同一个程序。坐在沙发上，配合鼠标和游戏手柄完成娱乐、资料浏览和 Codex 操作。

当前版本：**2.4.6**。界面为中文，使用 C# / .NET 8 / WinForms。程序集和本地配置目录沿用 `DisplaySceneSwitcher` 名称。

## 功能

- 五种显示场景：仅电脑、仅电视、同步显示、电脑主屏扩展、电视主屏扩展。
- 保存分辨率、刷新率、HDR 和屏幕左右布局偏好。
- 默认声音输出跟随显示场景；扩展模式跟随主屏，同步模式可指定输出。
- 切换前保存快照，切换后 **20 秒内确认保留**；超时通过恢复机制还原显示和声音。
- 两个侧键支持单击、双击、三击、按住组合、滚轮组合和连续退格。
- Codex 主窗口往返、整个宠物浮窗显示/隐藏。
- 默认只显示音量和静音提醒；双侧键长按可主动打开帮助。

## 默认鼠标操作

前键靠近鼠标头部，后键靠近手掌。默认前键为 `XBUTTON2`、后键为 `XBUTTON1`，鼠标页可交换前后键。

| 手势 | 操作 |
| --- | --- |
| 前键单击 | 切到 Codex；再次单击返回之前的窗口 |
| 前键双击 | Delete |
| 前键三击 | Esc |
| 前键双击，第二下按住 | 满 500 毫秒开始 Backspace，此后每 500 毫秒一次，松开停止 |
| 前键按住 + 滚轮上/下 | 音量增加/减少，每格 2 个百分点 |
| 前键按住 + 中键 | 静音/恢复 |
| 后键单击 | 整个 Codex 宠物浮窗显示/隐藏 |
| 后键双击 | Ctrl+Z 撤销 |
| 后键三击 | Enter |
| 后键按住 + 滚轮上/下 | 在已打开窗口之间反向/正向切换；松开后键确认 |
| 后键按住 + 中键 | 显示桌面/恢复窗口（Win+D） |
| 前后键同时按住 3 秒 | 显示使用说明，5 秒后自动隐藏 |

单击/双击默认等待 300 毫秒连击窗口，以区分三击。双键长按现在是**帮助**，不再触发显示器/电视切换。

普通左右键保持正常；托盘和鼠标页可暂停映射。独立的“沙发手势”与“滚轮音量”开关默认开启，不依赖实验室的“启用实际操作”复选框。

## 显示快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+Alt+1 | 仅电脑 |
| Ctrl+Alt+2 | 仅电视 |
| Ctrl+Alt+3 | 同步显示 |
| Ctrl+Alt+4 | 电脑为主屏，电视扩展 |
| Ctrl+Alt+5 | 电视为主屏，电脑扩展 |
| Ctrl+Alt+H | 切换电视 HDR |
| Ctrl+Alt+0 | 恢复之前的设置 |

## 构建和安装

需要 Windows x64、[.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。仅运行构建产物时需要 .NET 8 **Desktop Runtime x64**。

在项目目录用 PowerShell 执行：

```powershell
.\RunMouseTests.ps1
.\Build.ps1
.\Install.ps1 -NoStartup
```

构建产物在 `publish/`。`Install.ps1` 安装到 `%LOCALAPPDATA%\Programs\DisplaySceneSwitcher`，创建桌面快捷方式并启动托盘程序。不带 `-NoStartup` 会额外创建当前用户的登录启动快捷方式。

首次打开“设备与偏好”，选择电脑屏幕、电视和各自的播放设备，再尝试显示切换。设备自动识别包含 SONY / Realtek 名称启发式，其他设备应手动选择。

更新安装前从托盘退出旧版；显示切换正在等待确认或恢复时先处理该操作。关闭主窗口只是收起到托盘。

## 兼容范围

- 基础侧键依赖 Windows 鼠标事件；其他鼠标需自行验证按键编号和驱动转发行为。
- 双键 HID++ 直读适配的是 **MX Anywhere 3 蓝牙版本**（VID `046D`、PID `B025`），未宣称支持所有罗技鼠标或接收器连接。该路径只查询功能编号和读取报告，不修改鼠标映射。
- 在已验证设备上，Logi Options+ 转发的事件可能只包含一个侧键，因此不能用转发事件代替真实双键状态。此适配需保留罗技代理运行。
- Codex 宠物通过窗口身份及 `avatar-overlay` 页面路由识别，再使用窗口句柄显示/隐藏；不发送宠物全局快捷键。宠物必须已创建，尚未创建时请先从 Codex 的宠物入口显示一次。
- 宠物适配不是官方稳定 API；Codex 更新可能需要重新适配。应用自身也可能改变宠物可见状态。
- 系统权限差异或其他软件的输入处理可能影响模拟按键。`action-results.jsonl` 的 `sent` 表示 Windows 接受了输入，不等于目标软件必然执行。

## 开发与验证

本次整理沿用用户实测确认正常的 2.4.6 行为，没有重新设计按键。

- `RunMouseTests.ps1`：185 项纯逻辑回归测试，不操作当前窗口，不需要实体鼠标。
- Windows CI：运行上述测试并构建应用，不执行切屏、静音或桌面输入测试。
- `--mouse-gesture-test`：交互式桌面集成测试，会打开临时编辑器和窗口，实际发送 Delete、Ctrl+Z、Esc、Enter、Backspace 和 Alt+Tab；测试期间不要操作电脑。
- 其他诊断命令的副作用和使用方法见 [开发与测试](docs/development.md)。

实现说明见 [架构](docs/architecture.md)，版本整理见 [更新记录](CHANGELOG.md)。

## 配置与日志

本地数据位于 `%LOCALAPPDATA%\DisplaySceneSwitcher`，鼠标配置与日志位于其 `mouse/` 子目录。包括显示设备标识、声音设备标识、恢复快照、手势记录和窗口诊断信息。

仓库不包含个人设备配置、运行日志、截图、诊断报告、旧版本备份或提取的第三方应用代码。提交问题时请先检查诊断文件中的路径、设备和窗口信息。
